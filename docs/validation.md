## 2026-11-09 公开仓库后续修改

### 补丁提供者记录

以下环境、261/262 测试结果及性能数字来自用户提供的补丁说明，本次应用补丁尚未独立复核这些历史数字；不能将其作为当前源码的验收结果。

改动：论文上传、取文与选段在取得全站闸门之前完成PDF/DOCX解析，闸门内仍重新核验身份、角色、修订号和不可变版本字段；同一份字节不再在闸门内重复解析；`install-app` 后即建立唯一约束；界面样式改版。

环境：Frappe 16.55.2、Python 3.14.6、MariaDB **10.11.14**（不是部署固定的11.8）、Redis，全新站点、未执行 migrate。结果：后端262项中261项通过；唯一失败 `test_default_7_plus_7_complete_details_and_copied_images` 需要公开仓库未附带的7张菜单照片。修改前在同一环境另有 `test_update_counts_latest_content_once_and_unique_index_is_enforced` 失败（仅安装未 migrate 时缺唯一约束），修改后通过。新增4项论文闸门回归测试。

实测（120页文字PDF，取5次中位数）：一次上传持有闸门的时间从约0.9秒降到约20毫秒，整次请求耗时约减半；`get_version_text` 持有闸门的时间从约1秒降到约1毫秒。本轮未重跑写入型HTTP验收和真实浏览器验收。

### 当前独立验收

开发根和公开 checkout 均通过源码检查（137 个 Python 模块、50 份元数据、36 个 DocType、16 个 JavaScript 文件、5 个 LF shell 入口）及五份前端回归脚本。审阅后的 portals 前端检查各 44 项通过。无数据库 CI 保护在 Linux 上 17 项全部通过，包含已有目录、文件、正常及断裂符号链接的拒绝、非法 SITE、全新绝对及相对路径正例。

固定依赖镜像中的 Frappe 16.55.2、Python 3.14.10、MariaDB 11.8.6、Redis 8.0.2，使用新数据库和独立 sites/logs，只读绑定当前源码。审阅后完整后端回归为 239 项集成测试及 28 项格式测试，合计 267 项全部通过、无跳过，包含真实 PDF 子进程暂停期间另一连接完成撤权、五字段错配及 DOCX multipart 验证。全新安装在尚未迁移时即具备九类唯一索引及全局授权行，之后连续两次迁移通过。公开源单独运行工作餐测试：13 项中 12 项通过，仅照片检查明确跳过；0、1、7 张照片夹具分别验证跳过、拒绝和通过。开发根与公开 checkout 的 226 份公开应用文件逐字节一致，并与实际运行挂载源码一致。

浏览器实测教师查看学生进展、秘书兼学生切换、点餐保存及刷新、AI 私人记忆侧栏，以及注册页。覆盖 1280px 桌面、320/390px 窄屏，所测页面无横向溢出。缺图复验改用新的本机 origin：七张菜单图片实际返回 404，桌面及 320px 页面保留七张占位卡和订餐控件，份数改为2、金额50元并成功保存。公告另在 280px 视口、233px 内容容器内确认能收缩。界面扫描的两条侧边强调线提示属于用户补丁外观，保留。

本次修正另外为 CI 入口增加已有 bench 拒绝、站点名校验与无数据库保护测试，并把菜单业务断言和照片检查拆开。公开源码仅在七张照片全部缺失时明确跳过照片测试；部分缺失仍失败。没有重跑提供者的性能基准和完整写入型 HTTP 套件；GitHub Actions 尚未在 Ubuntu runner 上实际执行。并发解析的聚合内存容量未压测，不能把单进程内存上限等同于实际资源占用或站点容量。
