# 受控 AI 助手

当前实现使用 LangChain 模型适配与 LangGraph 显式流程，固定依赖见 `src/research_group/pyproject.toml`。默认 `rg_ai_mode=mock`，无需 API key；真实模型尚未联调。站内范围判定用于引导工作，服务端权限与固定工具白名单负责阻止越权。

## 身份、会话与记忆

- 所有人共用服务端模型配置；每人的会话、历史、memory、计划与运行状态分别存入 Frappe。
- 教师查询有权访问的正式科研记录，不能读取学生私人聊天或私人计划。讨论来源区分教师反馈和学生整理。
- 学生根据正式反馈规划工作，秘书读取获准排期和问卷汇总。秘书身份本身不授予私人论文或私人讨论权限。
- 记忆可关闭；保存、修改或删除记忆与计划需要本人确认。业务资料和记忆不能覆盖系统规则或角色权限。
- 删除、来源撤权和隐私版本变化会停止旧回合继续发布；派生正文保留来源依赖。已发送给供应商或已被人看到的内容无法追回。

## 固定工具与写操作

源码固定15个工具，按当前身份进一步缩减。无 SQL、Shell、浏览器、任意 URL、通用 CRUD、群发、账号管理或发布工具，不动态发现外部工具。

模型可以读取获准记录、提供站内操作指引、为本人记忆/计划/进展/预约/论文建议生成预览。确认接口不暴露为模型工具；本人在网页核对后，独立事务才实际写入，并复查权限、来源、期限及幂等身份。预约提交成功后仍待教师审批。

论文只读取本人明确选定、预览、授权且未过期的段落；不会自动发送整篇文件。建议需再次确认，标为 AI 辅助，原稿与教师意见保持原有身份。撤销授权或来源失效后屏蔽派生建议。

## 运行和费用边界

LangGraph依次执行身份验证、站内范围、授权上下文、模型调用、工具校验、读取或预览、最终来源核验。Frappe为唯一持久存储，不另配图checkpointer或Store。

模型支持Responses与Chat Completions两种适配路径；实际代码已用无网络MockTransport验证。关闭外部追踪、响应存储、自动重试和外部预览。API key仅由服务端配置，不向浏览器返回。

每用户有频率、每日轮次、文本存储和记忆数量上限；每轮限制输入、输出、请求数、工具数、时间和预算，另有全站执行/排队限制。参数及配置键见根README；这些初值不构成生产容量或费用保证。

真实端点、工具调用兼容性、建议质量、供应商条款、费用和部署容量需另行测试。没有在本次发布中调用付费API。
